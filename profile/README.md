### MechaMind Labs — Build The Unbuilt

Hands-on robotics, taught by building complete robots: CAD → electronics → firmware → ROS 2 → simulation → real hardware. Most repositories here are the code from a live workshop or program, recorded and free to follow on [YouTube](https://www.youtube.com/@MechaMindLabs).
